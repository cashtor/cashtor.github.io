# cashtor-web

Página de confirmación de cuenta y cambio de contraseña de **Cashtor**, la
aplicación con la que la familia lleva sus gastos.

Es un único archivo estático. Los enlaces que Supabase manda por correo
llegan aquí: confirma la cuenta, o deja elegir una contraseña nueva.

No contiene datos de nadie. La clave que lleva dentro es la *publicable*,
pensada para estar a la vista: por sí sola no da acceso a nada.
